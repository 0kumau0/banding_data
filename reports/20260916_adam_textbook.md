# 深層学習の教科書の Adam と、このコードの Adam

**対象**: 瀧雅人『これならわかる深層学習入門』（講談社）4章「勾配降下法」を読みながら、
`SGD_bear_20260909.R` / `examples/sgd_simulation.R` の Adam を読む人。

**結論を先に**: **式は教科書と同一。違うのは前提の反復回数だけ。**
教科書の既定値 `β₂ = 0.999` は10万歩以上歩く前提で選ばれており、
**我々の200〜400反復では記憶が実行全体より長くなって破綻する。**
2026-09-16 の実験でこれが実測で確定した（§7）。

---

## 1. 記号の対応

本の更新式は

```
Δw = −η · m / √(v + ε)
```

で、`m` と `v` の移動平均の定義と、`t` 乗で割るバイアス補正が手前に置かれている。

| 本 | このコード | 注 |
|---|---|---|
| `w` | `current_par` | **5個だけ**（深層学習は 10⁶〜10⁹ 個） |
| `E(w)` | `−` 対数尤度 | **符号が逆。我々は最大化** |
| `η` | `ALPHA` | **スカラーではなくベクトル**。係数ごとに値が違う |
| `m` | `m_hat` | バイアス補正後 |
| `v` | `v_hat` | バイアス補正後 |
| `ε` | `EPS_ADAM = 1e-8` | **位置が違う**（§5） |
| `∇E` | `grad_cachewise()` | **誤差逆伝播ではなく前進差分** |
| ミニバッチ | 単回捕獲個体の部分集合 | **層別抽出＋重み戻し**（§6 差③） |
| `t` | `iter` | 深層学習 10⁵〜10⁶、**我々 200〜400** ← **すべての違いの根** |

## 2. 4章の系譜

本は次の順に積み上げる。**各段が前段の欠点を1つずつ潰す構成**になっている。

### 2.1 最急降下法

```
w ← w − η ∇E(w)
```

全データで勾配を計算して1歩。**我々の `sampling_rate = 1.0` がこれ。**

### 2.2 確率的勾配降下法（SGD）

`E = Σ Eₙ` と分解できることを使い、一部だけで勾配を推定する。
**要件は不偏性**（推定した勾配の期待値が真の勾配に等しいこと）。

### 2.3 モメンタム

```
u ← μ u − η ∇E
w ← w + u
```

過去の移動方向を慣性として持ち越し、谷底のジグザグを減らす。

### 2.4 AdaGrad

```
h ← h + (∇E)²
w ← w − η ∇E / (√h + δ)
```

**勾配をその大きさで割る**という発想の最初。
欠点は `h` が単調増加なので**歩幅が永久に減り続ける**こと。

### 2.5 RMSprop

```
h ← ρ h + (1−ρ)(∇E)²
```

AdaGrad の `h` を指数移動平均に変えただけ。**この `ρ` が Adam の `β₂`。**

### 2.6 Adam

**モメンタム（2.3）＋ RMSprop（2.5）＋ バイアス補正。**

```
m ← β₁ m + (1−β₁) ∇E          一次モーメント（向き）
v ← β₂ v + (1−β₂) (∇E)²       二次モーメント（大きさ）
m̂ = m/(1−β₁ᵗ),  v̂ = v/(1−β₂ᵗ)  バイアス補正
Δw = −η m̂/√(v̂+ε)
```

## 3. コードとの逐行対応

```r
m <- BETA1 * m + (1 - BETA1) * g       # 本の m の移動平均
v <- beta2  * v + (1 - beta2)  * g^2   # 本の v の移動平均
m_hat <- m / (1 - BETA1^iter)          # 本の t 乗による補正
v_hat <- v / (1 - beta2^iter)
step  <- alpha * m_hat / (sqrt(v_hat) + EPS_ADAM)   # 本の Δw（ε の位置が違う）
step  <- pmax(pmin(step, mstep), -mstep)            # 本に無い。発散の歯止め
current_par <- current_par + step                   # 符号が本と逆（最大化）
```

**本の式と違うのは4点だけ**: 符号 / `η` がベクトル / `clip` の1行 / `ε` の位置。

---

## 4. バイアス補正 — なぜ `1 − βᵗ` で割るのか

### 4.1 導出

`m₀ = 0` と置くしかないが、**この初期値が嘘なので序盤の `m` は小さく出る。**
勾配が一定値 `g` だとして漸化式を展開すると、幾何級数の和になる。

```
mₜ = (1−β₁) Σ_{k=0}^{t−1} β₁ᵏ g = (1 − β₁ᵗ) g
```

**`mₜ` は `g` の `(1 − β₁ᵗ)` 倍にしかなっていない。** だから割り戻す。
`v` も同様に `vₜ = (1 − β₂ᵗ) g²`。

**「補正」といっても小細工ではなく、幾何級数の和を割り戻しているだけ。**
`t` が大きくなれば `βᵗ → 0` なので、補正は自然に消える。

### 4.2 1歩目がちょうど `η` になる

```
m₁ = 0.1 g,  v₁ = 0.001 g²
m̂₁ = g,      v̂₁ = g²
Δw = η · g/√(g²) = η
```

**勾配が 250 でも 0.001 でも、1歩目の幅は `η`。**
これが「学習率＝1歩で動く距離」と言える理由。

### 4.3 補正を省くとどうなるか

補正なしとありの歩幅の比は

```
(1 − β₁ᵗ) / √(1 − β₂ᵗ)
```

**分子と分母で `β` が違うのが効く。** `β₁` の damping はすぐ消えるが、
`β₂` の damping は平方根の中にいてなかなか消えない。

| `t` | `1−β₁ᵗ` | `√(1−β₂ᵗ)` | 歩幅の比 |
|---|---|---|---|
| 1 | 0.100 | 0.0316 | 3.2 倍 |
| 12 | 0.718 | 0.109 | **6.6 倍**（最大） |
| 100 | ≈1 | 0.309 | 3.2 倍 |
| **200** | ≈1 | 0.425 | **2.35 倍** |
| 1,000 | ≈1 | 0.795 | 1.3 倍 |
| 5,000 | ≈1 | 0.997 | 1.0 倍 |

（`β₁ = 0.9`, `β₂ = 0.999`）

**深層学習では数千歩で 1.0 に落ち着くので「最初だけの話」。
我々の200反復はその「最初だけ」の中にすっぽり入っている。**

> **注意**: 補正を省くと歩幅が 2.35倍に水増しされるので、
> **失速の症状を一部隠す**方向に働く。しかしこの倍率 `1/√(1−β₂ᵗ)` は
> **尤度面の形と何の関係もない量**で、`t` が進むだけで勝手に減る。
> 対策に使ってはいけない。

## 5. `ε` の位置 — 本は内側、このコードは外側

```
本      Δw = −η · m/√(v + ε)      ε はルートの中
コード  Δθ = +α · m̂/(√v̂ + ε)      ε はルートの外
```

**どちらも「Adam」。** 原論文（Kingma & Ba 2015）のアルゴリズム1は外側で、
PyTorch もそちら。内側は同論文が別の箇所で書いている変種で、TensorFlow 系が採る。

役割はどちらもゼロ割りの保険。違うのは**分母がどこまで小さくなれるか**。

| | 分母の下限 | 歩幅の最大倍率 | 正規化が崩れる境界 |
|---|---|---|---|
| 本（内側） | `√ε` = 10⁻⁴ | `m` の 10⁴ 倍 | `\|g\| < 10⁻⁴` |
| コード（外側） | `ε` = 10⁻⁸ | `m` の 10⁸ 倍 | `\|g\| < 10⁻⁸` |

**同じ `ε = 1e-8` でも効き方が4桁違う。** 内側のほうが保守的。
移植するときに値をそのまま持ってくると保険の強さが変わる
（外側の `1e-8` に相当する内側の値は `1e-16`）。

**我々の実行ではどちらでも完全に同じ。** 終盤でも勾配は 0.2〜12 あり、
`√v̂ ≈ 46`。`1e-8` は倍精度の桁で消える。
加えて `MAX_STEP` という別の保険があるので、暴走を止めるのは実質そちら。

## 6. 当てはめが教科書と違う7点

### 差① 符号 — 降下ではなく上昇

本は `E(w)` を最小化するので `−`。我々は対数尤度を最大化するので `+`。
`optim` に渡すときだけ `loglfscale = -1` で反転しているが、**Adam のループでは反転しない。**

### 差② 勾配が近似

本の `∇E` は誤差逆伝播で厳密。我々は前進差分（`1e-4`）で、**打ち切り誤差が乗る。**
しかも1回の勾配に `loglf` を6回呼ぶので、**1反復が深層学習の6倍以上高い。**
→ 反復数が200〜400しかない理由。差⑦につながる。

### 差③ ミニバッチが一様でない

```r
ll_hist <- out_multi$loglfmulti + out_single$loglfmulti / sampling_rate
```

| | 扱い |
|---|---|
| 複数回捕獲個体 | **毎回全部使う** |
| 単回捕獲個体 | 率 `r` で抽出し **`1/r` 倍して重みを戻す** |

統計でいう**層別抽出**。`1/r` は不偏性（§2.2 の要件）を保つため。
一様ミニバッチなら平均を取るだけで自動的に不偏なので、教科書にこの掛け算は出てこない。
**狙いは分散の削減**で、連結性の情報を持つ複数回個体を固定すると勾配のばらつきが小さくなる。

さらに**ポアソン項 `ll_pois` は個体ごとに分解できない**（景観全体の `λ` から計算する）。
**`E = Σ Eₙ` という前提が、我々の目的関数では一部しか成り立たない。**

### 差④ 部分集合を勾配の6回の評価のあいだ固定する

評価ごとに標本を引き直すと、`1e-4` の摂動が生む差より標本を変えた差のほうが大きく、
**勾配が標本のばらつきに埋もれる。**
教科書にこの注意が無いのは、**逆伝播が「そのミニバッチの勾配」を一度に返すから。**

### 差⑤ 学習率が係数ごとに違う

```r
ALPHA    <- c(dens_0 = 0.02, conn_0 = 0.03, conn_agri = 0.03, conn_wtr = 0.03, g0_1 = 0.02)
MAX_STEP <- c(dens_0 = 0.05, conn_0 = 0.10, conn_agri = 0.05, conn_wtr = 0.05, g0_1 = 0.05)
```

本が `η` をスカラーで書くのは、パラメータが 10⁶ 個あって個別調整が不可能だから。
**我々は5個なので調整できるし、する理由もある** — 各係数は物理的に意味が違う量
（log 密度・log 連結性・log 検出率）で、尤度面の曲率が桁で違う。

`MAX_STEP` は深層学習の**勾配クリッピング**に近いが、**勾配ではなく歩幅を切っている**点が違う。

### 差⑥ 「SGD のノイズは役に立つ」が成り立たない

教科書はミニバッチのノイズを鞍点からの脱出や汎化の観点で肯定的に扱う。
**我々にはどちらも無関係。** 欲しいのは最尤推定値そのもので、汎化する相手が存在しない。
**ノイズは純粋に害**で、間引くのは速度のためだけ。
だから「`rate = 1.0` で足りるならそれが最良」。深層学習の常識とここは逆になる。

### 差⑦ 反復数が記憶の長さより短い ← 最重要

§7 で扱う。

## 7. なぜ教科書の既定値がこの問題で壊れたのか

### 7.1 記憶 ＞ 実行長

`β₂` の指数移動平均が覚えている長さは約 `1/(1−β₂)` 反復。

| `β₂` | 記憶 | 深層学習（10⁵〜10⁶歩） | 我々（200〜400歩） |
|---|---|---|---|
| 0.999 | **約1000反復** | 全体の 1% 未満。十分「最近」 | **実行全体より長い** |

**教科書の既定値は10万歩以上歩く前提で選ばれている。**
その世界では1000歩ぶんの記憶は「ごく最近の平均」で、序盤の巨大な勾配は忘れられている。

**200反復では最初の勾配を最後まで覚えている。**
序盤に 250 あった勾配が終盤 0.2 に落ちても分母 `√v̂` はついてこない。結果

```
Δw = η m̂/√v̂ → η の 1/20 〜 1/33 まで潰れる
```

**同じ式、同じ既定値。前提の反復数だけが違う。**

### 7.2 実測（2026-09-16、検証台B・400反復・5条件）

同じ合成データに設定だけ変えて回した結果。

| `β₂` | `η` 倍率 | 全データ logL の差 | 終盤の判定 |
|---|---|---|---|
| 0.999 | ×1 | 8.05 | 失速 |
| 0.99 | ×1 | 5.58 | 失速 |
| **0.9** | **×1** | **0.19** | **一方向に進行中** |
| 0.99 | ×2 | 3.46 | 失速 |
| 0.99 | ×4 | 3.00 | 失速（`\|step\|` は `η` の 1/33） |

**400反復あっても `β₂ = 0.999` は 8.05 遅れたまま。`β₂ = 0.9` は 0.19。
同じデータ・同じ反復数で40倍の差。反復数の問題ではない。**

**`η` を4倍にしても救えない**（3.00 のまま失速）。
歩幅を増やしても、分母がそれ以上に潰す。

### 7.3 「進んだ距離」で見ると分かりやすい

200反復で累積何だけ動けるか（`Σ|Δw|`）。
必要距離 5.41 は `conn_wtr` が初期値 −1 から解 −6.41 まで動く距離（旧スケールの実データ）。

| | `η`×1 | ×2 | ×4 |
|---|---|---|---|
| `β₂` = 0.999 | 1.18 | 2.36 | **4.72 届かない** |
| `β₂` = 0.99 | 1.41 | 2.82 | 5.65 |
| `β₂` = **0.9** | 3.71 | **7.42 到達** | 14.83 |

**同じ `η`×2 で 2.36 と 7.42。**
`η` を4倍にして得られるのがちょうど4倍なのに対し、
**`β₂` を 0.999→0.9 にするだけで3倍**が手に入り、しかも両者は掛け合わさる。
**歩幅を増やすより、歩幅を潰しているものを外すほうが先。**

（この表は解説ウェブページのデモで操作できる。§9 参照）

### 7.4 バイアス補正にも同じ現象が起きている

§4.3 の表のとおり、`β₂ = 0.999` では `t = 200` でもまだ 5.5倍の割り増しが効いている。
**教科書が「最初だけ」と書く補正が、我々の実行では最後まで主役級。**

`β₂` を 0.9 に下げると、この問題も消える。

| | 補正が効いている期間 |
|---|---|
| `β₂ = 0.999` | **数千反復**（実行全体より長い） |
| `β₂ = 0.9` | **約30反復**（`1−0.9³⁰ = 0.958`） |

**記憶も・バイアス補正も・分母の居座りも、`β₂` を下げればまとめて実行長より短くなる。**
`β₂ = 0.9` だけが通った理由はこの一言に集約できる。

## 8. 標準的な対策をそのまま持ってきてはいけない

**Adam の収束証明には誤りがあった。**
Reddi, Kale & Kumar (2018) *On the Convergence of Adam and Beyond*（ICLR 最優秀論文）が
これを指摘し、**原因を `v` の指数移動平均に帰着させた**。提案された修正が **AMSGrad**。

```
v̂ₜ = max(v̂ₜ₋₁, vₜ)      単調非減少にする
```

**これを我々の問題に当てはめてはいけない。**
AMSGrad は「分母が小さくなりすぎる」ことを防ぐ修正で、**分母を大きい側に固定する**。
我々の症状は**分母が大きすぎて歩幅が潰れる**ことなので、**AMSGrad は失速を悪化させる。**

**同じ `v` が原因でも症状が逆。** 我々の対処は逆向き（`β₂` を下げて記憶を短くする）だった。

## 9. 教科書の性質のうち、我々でも成り立つもの

### スケール不変性

目的関数を `c` 倍しても `m` は `c` 倍、`√v` も `c` 倍なので**歩幅は変わらない。**

実務上これはかなり効く。対数尤度は個体数に比例して大きくなるので、
**`nind` が 100 でも 10,000 でも同じ `ALPHA` が使える。**
教科書が「平均 `1/N Σ` で書くか和 `Σ` で書くか」を気にしなくてよいのも同じ理由。

### 1歩目がちょうど `η`

§4.2 のとおり。バイアス補正があって初めて成り立つ性質。

## 10. まとめ

| | 教科書（深層学習） | このコード（ADCR） |
|---|---|---|
| 目的 | `E(w)` の最小化 | 対数尤度の最大化 |
| 勾配 | 誤差逆伝播（厳密） | 前進差分（近似、6回評価） |
| パラメータ数 | 10⁶〜 | **5** |
| 学習率 | スカラー1つ | **係数ごと** |
| ミニバッチ | 一様抽出 | **層別＋重み戻し** |
| ノイズ | 汎化に有用 | **害のみ** |
| 反復数 | 10⁵〜10⁶ | **200〜400** |
| `β₂ = 0.999` | 妥当（記憶は全体の1%） | **破綻（記憶 ＞ 実行全体）** |
| `ε` の位置 | ルートの中 | ルートの外（どちらも Adam） |

**4章を読むときは、`β₂` の既定値が「何歩歩く前提の値か」を意識すると、
このコードとの距離が測れる。**
